RxEventBus

RxEventBus class

全局事件总线

提供事件注册、发送、Sticky 缓存、优先级和并发/串行分发。

示例：

final token = EventToken();

RxEventBus.on<String>(
  module: 'chat',
  eventID: 1,
  token: token,
  callback: (id, uuid, data) async {
    print('收到事件 $id: $data');
  },
);

RxEventBus.notify<String>(
  module: 'chat',
  eventID: 1,
  data: 'Hello World',
);

// 移除事件
RxEventBus.offByToken(token);
