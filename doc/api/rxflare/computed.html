RxComputed<T> computed<T>(
  1. T fn()
)

创建一个计算属性的快捷方法。

fn 是计算函数，会返回计算值。 使用示例：

final count = RxState<int>(0);
final doubled = computed(() => count.value * 2);

doubled.listen((val) => print('doubled = $val'));

count.value = 5; // 输出: doubled = 10
