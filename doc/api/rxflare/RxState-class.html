RxState

RxState<T> class

RxState 是响应式状态的基础单元。

它封装了一个类型为 T 的值，并提供了自动依赖追踪和字段级（Map/List）更新机制

Implementers
  • RxComputed
  • RxFuture
Available extensions
  • RxAsyncExtension
  • RxIntOps
  • RxListToState

Constructors

RxState(T _value, {dynamic id, String? name})
创建一个响应式状态。 id 可选，默认为一个新的 Object。 name 可选，默认为 "RxState#序号"。
